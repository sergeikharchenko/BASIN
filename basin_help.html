BASIN User Guide & Mathematical Reference

Bayesian Sediment Source Apportionment Tool | Context-Dependent Modular Framework (Stan & R/Shiny)

BASIN is an open-source, modular Bayesian modeling framework for robust sediment source fingerprinting (SSF). Built on the Stan probabilistic programming language (utilizing Hamiltonian Monte Carlo and the No-U-Turn Sampler, HMC/NUTS), BASIN is designed around the principle of context-dependent modularity: because no single statistical parameterization is universally optimal across contrasting sampling designs and simplex geometries, BASIN exposes four independently configurable design axes—information sharing (pooling), residual error-scale & covariance architecture, source end-member representation, and non-conservatism buffering.

1. Input Data Format & Role Assignment

Your input dataset must be a standard comma-separated values (*.csv) file containing unique sample identifiers, class labels (source groups and target mixtures), and numeric columns of tracer properties (e.g., elemental geochemistry, colorimetric indices, fallout radionuclides, mineral magnetics, stable isotopes, or organic parameters):

Column 1: Sample ID Column 2: Group / Source Class Optional Covariate / Proxy Columns Columns K...N: Candidate Tracers
S_01 Forest Sorting Proxy (e.g., SSA, d50, TOC) Numeric tracer values (Al, Ti, L*, 137Cs...)
... multiple rows characterizing each potential source group ...
Mix_01 Target Mixture Label (e.g., Mix) Proxy value & optional Grouping Factor (e.g., Season / CoreLayer) Observed tracer values in the target mixture
Automatic Column Exclusion: Any column assigned as a Sorting / Enrichment Proxy or a Mixture Grouping Covariate in Section 1 of the sidebar is automatically excluded from the candidate tracer pool to prevent mathematical redundancy.

2. Intelligent Tracer Pre-Filtering

Overly rigid univariate filtering can dismantle the multidimensional geometry of catchment sources and force unmixing models into geometric equifinality. BASIN implements a sequential, geometry-preserving pre-filtering pipeline:

  • Proxy-Aware 1D Range Test: Evaluates whether target mixture means fall within the source min–max envelope (expanded by a 5% tolerance), optionally normalizing mixture values by the sorting proxy enrichment factor (Proxymix / Proxysrc). Selectable strictness modes: Raw only, Proxy-normalized, Strict (Both), or Lenient (Either).
  • Inter-Tracer Association Preservation Test (APT / GAPT) [Optional]: Identifies strongly co-migrating tracer pairs within the source domain (Spearman |ρ| > 0.85) and projects robust linear regressions (RLM/OLS) onto the targets. A tracer is excluded as strictly non-conservative if ≥ 50% of its structural links exhibit relative prediction errors exceeding 10%.
  • Multivariate PCA Convex-Hull Leverage Filter [Optional]: Computes the dimensionless displacement penalty L = D / R of target mixtures relative to the 2D Principal Component (PC1–PC2) source convex hull. If Lbase > 1.2, an iterative drop-out routine removes individual tracers whose exclusion pulls the mixtures back toward the source hull by > 5% (L−t < 0.95 · Lbase).
  • Kruskal–Wallis & Collinearity Pruning: Retains only tracers demonstrating statistically significant inter-source discrimination (non-parametric Kruskal–Wallis test, p < 0.05) and purges near-duplicate signals (|ρ| > 0.95).

3. Model Constructor: Four Configurable Design Axes

In baseline conservative form, BASIN models the expected tracer vector μf,i in mixture i as a linear convex combination of latent source vectors weighted by simplex proportions Pi (∑g Pi,g = 1, Pi,g ≥ 0). Target observations are evaluated under a heavy-tailed multivariate Student's t-distribution (ν = 4) to automatically downweight erratic biogeochemical or analytical outliers:

ymix,i ∼ 𝒯(ν = 4,  μf,i,  Σmix,i),    where  μf,i,t = ∑g=1G Pi,g · μsource,g,t

Axis 3.1 Cross-Sample Information Sharing (Pooling Modes)

  • Hierarchical Partial Pooling (Default for Ensembles): Parameterizes mixture proportions via a multi-level Dirichlet hierarchy centered on group-level (Plevel) or catchment-level global proportions (Pglobal):
    Pind,i ∼ Dirichlet(Pglobal · φind),    φind ∼ Gamma(2, 0.1)
    Partial pooling suppresses localized sampling noise and acts as a powerful computational accelerator for NUTS sampling. However, it is a double-edged sword: in event-dominated sediment cores, pooling shrinks rare, high-amplitude flood or typhoon pulses toward the background catchment mean.
  • Non-Hierarchical / Isolated Proportions (No Pooling): Assigns strictly independent priors Pind,i ∼ Dirichlet(α) to each sample. When analyzing an ensemble (Nmix > 1), residual error parameters are still learned jointly without shrinking individual proportions. When analyzing a single mixture (Nmix = 1), this yields strictly isolated inference with zero cross-sample borrowing of strength.
  • Complete Pooling: Estimates a single shared proportion vector P across all target rows (appropriate strictly for technical replicates of a single homogeneous event).

Axis 3.2a Residual Error-Scale Specification

The parameterization of the diagonal scale vector σtot,i governing Σmix,i is the first-order determinant of single-mixture accuracy:

  • 1. Free Regularized Scales (Adaptive M-Estimator, Default): Assigns each tracer an independent residual scale anchored by a zero-peaked Half-Student-t prior on standardized data:
    σtot,i,t = σmix,t,    σmix,t ∼ Half-Student-t(3, 0, σprior = 1.0)
    Decoupling σtot from Pi,g2 eliminates the mathematical penalty against pure end-members (Pg = 0 or 1), preventing centroid shrinkage on boundary-rich, multi-source mixtures while remaining well-identified even at Nmix = 1.
  • 2. Process-Error Only (Source-Variance Propagated): Deterministically propagates intra-source variances σ2src,g,t into the mixture likelihood without estimating free residual scales:
    σtot,i,t = √∑g=1G Pi,g2 · σ2src,g,t
    Because the log-likelihood normalization term −½∑t ln(∑g Pg2σ2src,g,t) is maximized at Pg = 1/G, this mode induces centroid shrinkage on boundary mixtures, but provides superior interval calibration on interior-dominated, two-source mixtures with strongly heterogeneous source variances.

Axis 3.2b Inter-Tracer Covariance Architecture

  • Independent (Diagonal Error Matrix): Σmix,i = diag(σ2tot,i). Fastest execution; treats tracers as conditionally independent.
  • Target Mixture Covariance (Recommended for Ensembles): Factorizes the residual covariance via a Cholesky correlation factor regularized by an LKJ prior:
    Σmix,i = diag(σtot,i) · LΩLΩ⊤ · diag(σtot,i),    LΩ ∼ LKJcorr(4)
    Extracts co-migration patterns directly from target ensembles (Nmix > 1) or applies soft LKJ regularization at Nmix = 1.
  • Full Bayes (Source + Mixture Covariance, Ideal for Nmix = 1): Simultaneously models source observations via group-specific multivariate normal distributions ysource,j ∼ MVN(μsource,g, Σsrc,g) with Cholesky factors LΩ,src,g ∼ LKJcorr(2). Propagating empirical source covariance provides decisive structural regularization for isolated targets (Nmix = 1).

Axis 3.3 Source End-Member Representation

  • Parametric Group Centroids (Standard): Represents each source group by its latent multivariate mean vector μsource,g.
  • Sub-Sampled Erosion Hotspots (Hybrid: Free Scale + SD2 / k) Experimental Preview: Scales propagated intra-source variance by k active sub-samples (σ2src,g,t / k) alongside free residual scales.
  • Discrete Sample Simplex (Nested Convex Hull) Experimental Preview: Models each mixture as a non-parametric convex combination of individual source samples within each group via softmax-transformed latent weights ηsub.

Axis 3.4 Non-Conservatism, Compositional & Spatial Modules

  • Sorting Correction (Beta): Applies a non-linear exponential correction to source means in raw positive tracer space, tied to the standardized Z-score difference of the sorting proxy between mixture i and source group g:
    μcorr,g,t = μsource,g,t · exp(βsorting,t · (Proxymix,i − Proxysource,g)),    βsorting,t ∼ 𝒩(0, 0.2)
  • Systematic Bias Absorption (δbias): Introduces a heavy-tailed displacement vector δbias,t ∼ 𝒯(3, 0, 0.1) into the mass-balance equation. Together with Beta-correction and the Student-t4 likelihood, this establishes a three-way division of labor: (i) βsorting captures proxy-proportional granulometric shifts; (ii) δbias isolates ensemble-wide systematic offsets (e.g., heavy-mineral lag or minor unsampled source contributions of ≤ 5–10%); and (iii) the heavy 𝒯4 tails downweight erratic, sample-specific redox or analytical excursions.
  • Compositional Transform (CoDA / ILR): Maps strictly positive compositional data into an open Euclidean space via an orthonormal Isometric Log-Ratio (ILR) basis matrix V, unmixing in raw proportion space via softmax(Vμsource,g) before projecting back to ILR coordinates. Warning: Do not activate CoDA on datasets affected by uncorrected hydrodynamic sorting, as tracer-specific sorting violates linear mixing in log-ratio space.
  • Prior Geographical / Connectivity Weights: Integrates independent geomorphic information (e.g., source polygon area, RUSLE erosion rate, or Sediment Connectivity Index IC) into the Dirichlet concentration vector α = wconn (default wconn = [1, 1, ...]).
  • Unsampled 'Ghost' Source Detector (G + 1) Experimental Preview: Appends a latent (G + 1)-th end-member anchored via outward Frank–Wolfe simplex projection to screen for major missing erosion sources, with orthogonalized bias projection to maintain identifiability.

4. Practitioner Deployment Guidelines

Use the following empirical decision matrix to configure BASIN for your specific study design:

Sampling Design & Regime Pooling Mode (Axis 3.1) Error Scale & Covariance (Axis 3.2) Recommended Buffers (Axis 3.4)
1. Single conservative or weakly non-conservative target (Nmix = 1) No Pooling (Isolated) Free Regularized Scales + Full Bayes Covariance None (keep parsimonious)
2. Single target with suspected transport sorting / shifts (Nmix = 1) No Pooling (Isolated) Free Regularized Scales + Independent or MixCov Sorting Correction (Beta) &/or Bias Absorption (avoid unbuffered Full Bayes)
3. Stationary ensemble (replicate traps, background core layers) Hierarchical Partial Pooling Free Scales (or Process-Error if interior-rich) + MixCov Optional; compare via PSIS-LOO
4. Multi-event ensemble or core with extreme flood/typhoon pulses No Pooling (preserves pulse amplitude) Free Regularized Scales + MixCov or Full Bayes Bias Absorption + Beta (if proxy available)
5. Interior-rich, 2-source design with heterogeneous source variances No Pooling or Hierarchical Process-Error Only (calibrates 50% CI coverage) None unless sorting is severe

5. Mass-Balance Reconstruction & Bayesian Model Comparison

  • Multi-Tracer Mass-Balance Reconstruction (Tab 4): Back-calculates expected tracer values from posterior median proportions and reports per-tracer Mean Bias (%), sMAPE (%) (Symmetric Mean Absolute Percentage Error), and Error vs. Source Range (NRMSEsrc, %). In models with Beta-correction enabled, toggle between Conservative (No Beta) and Corrected (+Beta Proxy) reconstructions.
  • Bayesian Cross-Validation (Tab 7 — PSIS-LOO & Exact LOO-CV): Evaluates out-of-sample Expected Log Predictive Density (elpd_loo) to rank competing model configurations fitted to the same dataset, same tracer subset, and same measurement scale (the top-ranked model has elpd_diff = 0).
    • Pareto k Diagnostics: Mixtures with Pareto shape k > 0.7 represent highly influential observations or localized geochemical anomalies. When k > 0.7, use Run Exact LOO-CV to refit the model holding out one mixture at a time.
    • Interpretational Caveat: Under No Pooling, each mixture has an independent Pind,i; Exact LOO therefore evaluates prior-predictive generalizability to a new sample rather than conditional within-ensemble interpolation.

6. Validation with Virtual Mixtures

The Validation (virtual mixtures) tab generates synthetic mixtures with known ground-truth proportions across four selectable generation regimes:

  1. Full Stochastic (Dirichlet Props + MVN Tracers): Random Dirichlet proportions paired with source signatures drawn from multivariate normal distributions (respecting empirical source covariance).
  2. Semi-Stochastic (Simplex Grid + MVN Tracers): Regular simplex grid proportions (including pure vertices Pg = 0 and 1) paired with multivariate normal source draws.
  3. Semi-Deterministic (Dirichlet Props + Mean Tracers): Random Dirichlet proportions paired with uniform source group means.
  4. Full Deterministic (Simplex Grid + Mean Tracers): Regular simplex grid proportions paired with uniform source group means.
Reported Validation & Calibration Metrics:
  • MAE / RMSE / ME / R2: Point-estimate inaccuracy, root-mean-square error, signed bias, and linear coefficient of determination between true and posterior median proportions.
  • CRPS & NSE: Continuous Ranked Probability Score (proper scoring rule evaluating the entire posterior distribution) and Nash–Sutcliffe Efficiency (> 0.50 good, > 0.70 excellent).
  • W50 / W95 & P50 (adj) / P95 (adj): Mean widths of the 50% and 95% credible intervals and their empirical coverage probabilities incorporating a boundary tolerance of ϵ = 0.015 (accounting for the mathematical constraint that open-simplex MCMC intervals (0, 1) cannot contain exact 0.0 or 1.0 boundary vertices).
  • CSI (>50%) & HR (>50%): Critical Success Index and Hit Rate for correctly identifying the dominant sediment source (> 50% contribution).

7. Inference Engine, MCMC Diagnostics & Automated Workspaces

Mandatory MCMC Convergence Checks (Results Tab):
  • Gelman–Rubin Statistic (&Rcirc; / Rhat): Must be strictly < 1.05 (ideally < 1.01) across all source proportions.
  • Effective Sample Size (neff): Should exceed 400–700 independent draws. If convergence is poor, increase iterations or simplify the active module combination.

In addition to manual CSV/ZIP download buttons in the interface, BASIN automatically archives every completed model run on disk:

  • BASIN_Workspaces/[Timestamp]_[Model_Tag]/: Stores 00_Run_Metadata.csv, 01_MCMC_Raw_Chains.csv, 02_Stanfit_Object.rds, global posterior density and Beta-coefficient plots (.png), per-chain elapsed times (05_Chain_Times.csv), and 06_Aggregated_Summary.csv, while appending run diagnostics to BASIN_Workspaces/Runtime_Log.csv.
  • BASIN_Saved_Results/: Exports sample-by-sample mean and median apportionment tables (Results_[Timestamp].csv).
